# 대학까지 몇 점? — v1.1.0 수정판

2026년 10월 전국연합학력평가 성적으로 **대학 지원참고점수와 내 점수의 차이**를 확인하는 진학상담 웹사이트입니다.
담임교사·학생·학부모가 휴대전화에서 바로 쓸 수 있고, 서버 없이 **GitHub Pages**에서 돌아갑니다.

- 지금: **가채점 원점수** 입력 (고1·고2는 원점수 → 표준점수·백분위·등급·상위누적 자동 변환)
- 성적표 배부 후: **공식 성적표** 입력 (과목마다 표준점수·백분위·등급 중 **아는 값 1개 이상**만 넣으면 됨)

## 2. GitHub Pages로 올리기 (처음 하는 선생님용)

### ① 저장소 만들기
1. <https://github.com> 에 로그인합니다.
2. 오른쪽 위 **＋** ▸ **New repository** 를 누릅니다.
3. **Repository name** 에 영어로 이름을 적습니다. 예: `daehak-score-2026-10`
4. **Public** 을 고릅니다. (아래 '자료 공개 주의'를 먼저 읽으세요.)
5. 맨 아래 **Create repository** 를 누릅니다.

### ② 파일 올리기
1. 받은 ZIP 파일의 압축을 풉니다. `university-score-explorer` 폴더 **안의 파일과 폴더**를 씁니다.
2. 새 저장소 화면에서 **uploading an existing file** 글자를 누릅니다.
3. 폴더 안의 `index.html`, `README.md`, `css`, `js`, `data`, `docs`, `tests`, `tools` 를 **한꺼번에 끌어다 놓습니다**. (폴더째 끌어 놓으면 구조가 유지됩니다.)
4. 아래 **Commit changes** 를 누릅니다.
5. 저장소 첫 화면에 `index.html`이 **맨 위(최상위)** 에 보여야 합니다. `university-score-explorer/index.html`처럼 한 단계 안에 들어가 있으면 주소가 달라지니 다시 올리세요.

### ③ GitHub Pages 켜기
1. 저장소 위쪽 **Settings** ▸ 왼쪽 **Pages** 로 갑니다.
2. **Source**: `Deploy from a branch`
3. **Branch**: `main` / `/(root)` 를 고르고 **Save**.
4. 1~3분 뒤 같은 화면 위쪽에 주소가 나타납니다.
   예: `https://mathlhk15-glitch.github.io/daehak-score-2026-10/`

### ④ 주소 확인
- 휴대전화로 주소를 열어 학년 ▸ 원점수 ▸ **대학 찾기**가 되는지 확인합니다.
- 학교 홈페이지·밴드·lhk15 포털 카드에 이 주소를 연결합니다.
- 고친 파일을 다시 올리면 1~3분 뒤 반영됩니다. 휴대전화에서 옛 화면이 보이면 새로고침하세요.

## 3. 자료 공개 주의 (꼭 읽어 주세요)

- `data/grade*.js`에는 **이투스 지원참고표 원자료**가 들어 있습니다. Public 저장소에 올리면 누구나 내려받을 수 있습니다.
- 이투스 자료의 **재배포 허용 범위를 확인한 뒤** 공개하세요. 파일 이름을 바꾸거나 JavaScript 안에 넣는 방식으로는 공개를 막을 수 없습니다.
- 확인 전이라면:
  - 교내에서만 쓰기: ZIP을 교사 PC·공유폴더에 두고 `index.html`을 열어 쓰기 (인터넷 불필요)
  - 비공개 저장소 + Pages는 GitHub 유료 요금제가 필요합니다.

## 4. 개인정보
- 성적은 서버로 전송되지 않고 **브라우저 안에서만** 계산합니다.
- 기본값은 '저장 안 함'. 메뉴 ▸ **이 기기에 입력값 기억하기**를 켠 경우에만 그 기기에 저장됩니다.
- 공용 PC에서는 메뉴 ▸ **모든 입력값 지우기**.
- 교사용 도구는 메뉴에 숨겨 둔 것일 뿐 **비밀번호 보호가 아닙니다.** CSV에는 이름 대신 익명 코드를 쓰세요.

## 5. 자동 검수 다시 돌리기 (선택)
Node.js가 있는 컴퓨터에서 `node tests/run_tests.js` → `tests/test-results.txt`에 결과가 저장됩니다.


## v1.1.0 주요 변경
- 고3 탐구 원점수는 정수만 입력하며, 학년·성적 모드 변경 시 비교척도를 자동 초기화합니다.
- 학년 전환 시 비교 목록을 초기화하고, 임시 대학/학과 검색에서 원래 희망 조건으로 돌아갈 수 있습니다.
- 모바일 브라우저 뒤로가기 시 상세/교사용 패널을 우선 닫습니다.
- CSV 수식 삽입 방지, 저장되는 상태에서 학생 이름 제외, 학과 유사어 개선, 결과 요약 복사를 반영했습니다.
- 공식 성적표 모드를 활성화한 경우 초기 선택은 공식 모드로 변경됩니다. 단, 공식 성적표용 확정 대학 배치자료와 실제 표준점수 대응표는 별도로 준비해야 합니다.
- 고3 원점수 비교는 선택과목 차이를 반영한 대학별 실제 합격예측이 아닙니다.
- 공개 GitHub 배포 전 이투스 배치표 데이터의 공개 재배포 허용 범위를 반드시 확인하십시오.

## 추가 검수 사항(v1.1.1)
- 기존 회귀 검사: `node tests/run_tests.js` (101건 통과)
- 신규 회귀 검사: `node tests/regression_1_1.js` (8건 통과)
- 고1·2 가채점 점수의 다음 등급컷 및 전국 평균은 원본 추정 자료를 활용합니다.
- 고3 단계별 모집은 기본적으로 1단계를 숨기고, 결과의 상세 필터에서 다시 표시할 수 있습니다. 원본 행은 삭제하지 않았습니다.
- 지역인재 전형명 빠른 필터가 있지만, 현재 고3 원본 배치표에는 '지역인재'라는 전형명이 없어 검색 결과가 0건일 수 있습니다. 실제 전형 자격은 별도 모집요강 확인이 필요합니다.
- 공식 성적표와 공식 점수 대응표가 아직 제공되지 않았으므로 공식 점수 일부 입력의 '계산 가능한 항목만 표시' 규칙을 유지합니다. 가채점 배치표와 공식 입력 점수를 혼동하지 않도록 안내합니다.
- 모바일 뒤로가기·브라우저 인쇄는 실제 휴대전화에서 최종 확인을 권장합니다(정적 분석과 Node 테스트만 진행).

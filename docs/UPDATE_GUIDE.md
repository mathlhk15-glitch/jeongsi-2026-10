# 공식 성적표·새 시험 업데이트 설명서

프로그램 코드는 그대로 두고 **데이터 파일과 설정 파일만** 바꾸는 방식입니다.

---

## A. 10월 학평 공식 성적표가 배부되었을 때 (가장 간단)

1. `data/metadata.js`를 메모장으로 엽니다.
2. 다음 한 줄을 바꿉니다.
   ```js
   enabled: false,   // ← 성적표 배부 후 true 로 변경
   ```
   →
   ```js
   enabled: true,
   ```
3. GitHub 저장소에서 `data/metadata.js`를 새 파일로 올립니다(같은 이름으로 덮어쓰기).

이것만으로 학생들은 '공식 성적표'를 골라 **과목마다 표준점수·백분위·등급 중 아는 값**을 넣을 수 있습니다.

- 네 과목(국·수·탐1·탐2) **표준점수가 모두** 있으면 → 표준점수 합으로 정확히 비교
- 네 과목 **백분위가 모두** 있으면 → 백분위 합(국+수+탐 평균)으로 정확히 비교
- 일부만 있으면 → 비교 가능한 것만 보여 주고 "○○ 표준점수가 더 필요합니다"라고 안내
- 등급만으로는 표준점수·백분위를 추정하지 않습니다.
- 가채점 입력은 지워지지 않고 따로 남아 '점수 실험 ▸ 가채점 예상 vs 공식 성적표'에서 비교됩니다.

> 미리 점검하려면: 메뉴 ▸ 교사용 도구 ▸ '공식 성적표 모드 미리보기'를 켜면 그 기기에서만 열립니다.

## B. 공식 점수 대응표를 넣고 싶을 때 (선택)

성적표 배부 후 과목별 **표준점수 ↔ 백분위 ↔ 등급 ↔ 상위누적** 공식 대응표를 구했다면, 학생이 하나만 입력해도 나머지를 자동으로 채울 수 있습니다.

1. `data/official/` 폴더를 만들고 `grade3-official.js` 같은 파일을 만듭니다.
   ```js
   window.UDATA = window.UDATA || {};
   window.UDATA["g3_official"] = {
     meta: { source: "평가원(또는 교육청) 채점결과", baseDate: "2026-11-20", version: "official-2026-10-g3" },
     conv: {
       // 각 행: [표준점수, 백분위, 등급, 상위누적%]  — 공식 자료 그대로
       kor:  [[147, 100, 1, 0.1], [146, 100, 1, 0.2] /* … */],
       math: [ /* … */ ],
       t1:   [ /* … 탐구 과목별로 다르면 학생 선택과목에 맞는 표를 따로 관리해야 합니다 */ ],
       t2:   [ /* … */ ]
     },
     // (선택) 국수탐 합 상위누적. 키 이름은 고1·고2 자료와 같습니다.
     cum: { pct_cum: [/* 상위누적% */], std_kms: [/* 그때 표준점수 합 */], pct_kms: [/* 그때 백분위 합 */] }
   };
   ```
   - 고1·고2는 `g1_official`·`g2_official`, 과목 키는 `kor, math, soc, sci` 입니다.
2. `data/metadata.js` 에서 경로를 적습니다.
   ```js
   files: { g1: null, g2: null, g3: "data/official/grade3-official.js" }
   ```
3. 자동 보완 규칙(코드에 이미 들어 있음)
   - 학생이 직접 넣은 값이 1순위
   - 대응표에서 **값이 하나로 정해질 때만** 빈칸을 채움 (예: 백분위 90에 표준점수가 두 개면 표준점수는 비워 둠)
   - 입력한 지표끼리 대응표와 맞지 않으면 "다시 확인하세요" 경고
   - `cum`이 있으면 공식 모드에서도 전국 상위누적을 보여 줌

## C. 새 시험(예: 11월 수능, 내년 3월 학평) 배치표가 왔을 때

1. 이투스 엑셀 파일을 한 폴더에 **원래 이름 그대로** 모읍니다.
   (파일명에 `고1`+`지원참고표`, `고1`+`한문제더`, `고2`…, `고3`+`지원참고표` 가 들어 있으면 자동 인식)
2. 파이썬이 있는 컴퓨터에서 실행합니다.
   ```
   pip install openpyxl
   python3 tools/build_data.py "엑셀파일폴더"
   ```
3. `data/grade1.js`, `grade2.js`, `grade3.js`, `validation.js` 가 새로 만들어집니다.
4. `tools/build_data.py` 안의 `META_COMMON`(시험 연도·월·이름·참고표 모집연도)을 새 시험에 맞게 고칩니다.
5. `data/metadata.js`의 `updatedAt`, 학년별 `target`(실제 대입 학년도)을 확인합니다.
6. 아래 검증을 한 뒤 `data/` 폴더를 GitHub에 올립니다.

### 엑셀 구조가 바뀐 경우
변환기는 현재 이투스 양식(시트 이름 `대학지원가능점수`, `원표백등`, `상위누적`, `등급컷`, 7~8행 머리글)을 기준으로 합니다.
시트 이름이나 열 위치가 바뀌면 `tools/build_data.py`의 열 문자(예: `"M"`, `"N"`, `"O"`)를 새 위치로 고쳐야 합니다.

## D. 업데이트 후 반드시 할 검증

| 확인 | 방법 |
|---|---|
| 모집단위 수가 엑셀 행 수와 같은가 | 메뉴 ▸ 자료 출처 및 업데이트 표의 '모집단위 수' |
| 원본 의심 항목 | 메뉴 ▸ 데이터 검증 정보 (새로 생긴 항목 확인) |
| 원점수 → 표준점수 변환이 엑셀과 같은가 | '한문제더' 파일에 학생 점수를 넣고 나온 표점·백분위·등급과 웹 결과 비교 (2~3명) |
| 상위누적이 엑셀과 같은가 | 위와 같은 학생의 '합(상위누적)' 칸과 웹의 '전국 상위 ○%' 비교 |
| 검색 결과가 엑셀과 같은가 | '한문제더'에서 검색 버튼을 누른 결과(군별 건수)와 웹 '점수 실험 ▸ 지금~실험 점수 사이 모집단위' 비교 |
| 자동 검수 | `node tests/run_tests.js` (엑셀 대조값은 `tests/fixtures/` 에 새로 뽑아 넣어야 함) |
| 휴대전화 화면 | 안드로이드·아이폰에서 입력 → 대학 찾기 → 상세 → 보고서 인쇄 |

공식 성적표를 켠 뒤에는 실제 성적표 1~2장으로 '표준점수만', '백분위만', '등급만' 입력해 보고 안내 문구가 맞게 나오는지 확인하세요.
